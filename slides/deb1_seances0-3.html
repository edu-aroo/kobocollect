Séance 1 — Construire un formulaire sur la plateforme

Formbuilder : ajouter une question

  1. NOUVEAU → Construire à partir de zéro → détails du projet
  2. + → taper le libellé → choisir le type
  3. ⚙ : nom de colonne, réponse obligatoire, indication
  4. Aperçu → ENREGISTRER

Toujours : le libellé d’abord, puis le type.

Choisir le bon type

Information Type
nombre de pêcheurs Nombre (integer)
poids, longueur Décimal (decimal)
village, engin Sélectionner un (select_one)
espèces présentes Sélectionner plusieurs (select_multiple)
date, position, photo date, geopoint, image
consigne sans réponse Note (note)

Comptage en texte, village en texte, poids en entier : les trois erreurs classiques.

Libellé et valeur d’un choix

  • libellé : ce qu’on lit — Pêche à pied (glanage)
  • valeur (XML value) : ce qui est enregistré — glanage
  • courte, minuscules, sans espace ni accent ; la fixer avant la collecte

Obligatoire : seulement ce sans quoi la fiche est inutilisable. Une question obligatoire sans réponse possible = des données fausses.

Règles des noms

  • commence par une lettre ; lettres, chiffres, _
  • minuscules, sans accent, sans - (pensez à R et Excel)
  • unique ; jamais renommé une fois la collecte commencée
  • settings : form_title, form_id, version (2026-01-v1)
