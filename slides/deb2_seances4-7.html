Séance 4 — Importer, déployer et collecter

Importer un XLSForm

  • nouveau projet : NOUVEAU → Téléverser un XLSForm
  • projet existant : FORMULAIRE → Plus d’actions → Remplacer le formulaire

KoboToolbox n’affiche que la première erreur. [row : 9] = ligne Excel (en-tête = 1).

Lire les messages (fichier k04_erreurs.xlsx)

Faire l’exercice en direct : projeter KoboToolbox, importer, lire, corriger dans Excel, ré-importer.

Déployer, redéployer

  • DÉPLOYER → le formulaire reçoit des données
  • correction → REDÉPLOYER : les données déjà reçues sont conservées (__version__)
  • sans risque : libellés, indications, traductions, ajout de questions ou de choix
  • à éviter : renommer un name, changer le name d’un choix, changer un type

Partager et tester

  • PARAMÈTRES → Partage : enquêteur = Voir le formulaire + Ajouter des soumissions
  • 5 à 10 fiches de test (valeurs normales et extrêmes), sur les vrais appareils
  • vérifier le tableau et un export → corriger → supprimer les tests

Séance 5 — Consulter et télécharger les données

L’onglet DONNÉES

  • Tableau : filtrer, ouvrir, modifier, valider
  • Rapports, carte, Galerie
  • Téléchargements : XLS + Valeurs et en-têtes XML pour l’analyse

Regarder les données chaque jour pendant la collecte.

Fiche de débarquement
  • select_multiple : 1 colonne + 1 colonne 0/1 par choix
  • _uuid : identifiant permanent · _submission_time : réception (UTC) · _index : n° de ligne de cet export

Attention aux versions

  • Crabe ajouté en v2 → especes/crabe = 0 pour les fiches v1 parce que le choix n’existait pas
  • toujours regarder __version__ avant de comparer des périodes
  • dates : date_debarq, pas _submission_time
