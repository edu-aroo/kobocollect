A1 · Filtered choice lists (choice_filter)A1 · Les listes de choix filtrées (choice_filter)

~2 h

By the end of this session you will be able to

  • show only part of a choice list, depending on a previous answer, with choice_filter;
  • add filter columns to the choices sheet and write the filter expression;
  • filter on a select_multiple answer (show only the choices ticked before, or the ones not ticked);
  • use several filter columns, and avoid the usual mistakes.

À la fin de cette séance vous saurez

  • n’afficher qu’une partie d’une liste de choix, selon une réponse précédente, avec choice_filter ;
  • ajouter des colonnes de filtre à la feuille choices et écrire l’expression de filtre ;
  • filtrer selon une réponse select_multiple (n’afficher que les choix cochés avant, ou ceux non cochés) ;
  • utiliser plusieurs colonnes de filtre, et éviter les erreurs habituelles.

Shorter lists, fewer errorsDes listes plus courtes, moins d’erreurs

Simulated context. The fisheries officers of the bay note the main species observed on three habitats: coral reef, seagrass meadow and mangrove. A single list of 10 species lets an officer choose “mud crab” on a coral reef — an error that the analysis will not see. You want the list to show only the species of the habitat chosen. Later in the form, among the species targeted by the fishers that day, the officer must say which one brings the most money: the list should contain only the species ticked just before. Form: ⇩ a01_choice_filter.xlsx

Contexte simulé. Les agents de pêche de la baie notent l’espèce principale observée sur trois habitats : récif corallien, herbier marin et mangrove. Une liste unique de 10 espèces permet à un agent de choisir « crabe de mangrove » sur un récif corallien — une erreur que l’analyse ne verra pas. Vous voulez que la liste n’affiche que les espèces de l’habitat choisi. Plus loin, parmi les espèces ciblées par les pêcheurs ce jour-là, l’agent doit dire laquelle rapporte le plus : la liste ne doit contenir que les espèces cochées juste avant. Formulaire : ⇩ a01_choice_filter.xlsx

  • On the left of =: the name of the column of choices (no ${}, no quotes). On the right: the answer, ${habitat}.
  • The expression is evaluated for each choice. Inside it, name and label are the columns of the choice itself: selected(${especes_ciblees}, name) = the name of this choice is among the species ticked.
  • A choice whose filter cell is empty never satisfies habitat = ${habitat}: it is never shown. For a choice that must always appear (e.g. Autre), see below.
  • À gauche du = : le nom de la colonne de choices (sans ${}, sans apostrophes). À droite : la réponse, ${habitat}.
  • L’expression est évaluée pour chaque choix. À l’intérieur, name et label sont les colonnes du choix lui-même : selected(${especes_ciblees}, name) = le name de ce choix est parmi les espèces cochées.
  • Un choix dont la cellule de filtre est vide ne vérifie jamais habitat = ${habitat} : il n’est jamais affiché. Pour un choix qui doit toujours apparaître (ex. Autre), voir plus bas.

Common mistakes. Values of the filter column that do not match the name of the parent choices exactly (Recif vs recif, a space at the end of the cell); writing the label of the habitat in the filter column; ${habitat} = habitat works too, but 'habitat' = ${habitat} (quotes) compares a fixed text and shows nothing; a filter on a question placed before its parent. The Formbuilder does not edit choice_filter: write it in the XLSForm and upload with Remplacer le formulaire (Replace form). If you then open the form in the Formbuilder and save, check that the filter is still there.

Data are not filtered. The filter only changes what is shown. All the choices exist in the export (the 0/1 columns of a select_multiple include every choice of the list, even those never shown).

Erreurs fréquentes. Valeurs de la colonne de filtre qui ne correspondent pas exactement au name des choix parents (Recif au lieu de recif, une espace en fin de cellule) ; écrire le libellé de l’habitat dans la colonne de filtre ; ${habitat} = habitat fonctionne aussi, mais 'habitat' = ${habitat} (apostrophes) compare un texte fixe et n’affiche rien ; un filtre sur une question placée avant son parent. Le Formbuilder ne modifie pas choice_filter : écrivez-le dans le XLSForm et importez avec Remplacer le formulaire (Replace form). Si vous ouvrez ensuite le formulaire dans le Formbuilder et l’enregistrez, vérifiez que le filtre est toujours là.

Les données ne sont pas filtrées. Le filtre ne change que ce qui est affiché. Tous les choix existent dans l’export (les colonnes 0/1 d’un select_multiple incluent chaque choix de la liste, même ceux jamais affichés).

Application work A1

  1. Upload a01_choice_filter.xlsx and test: how many species are offered for each habitat?
  2. In the second part, tick Poulpe, Seiche and Huître: how many choices does the last question show?
  3. Add a choice autre (Autre espèce) that is shown for every habitat, and a text question Précisez shown only when autre is chosen.
  4. Add a question espece_secondaire (Deuxième espèce observée), same list, filtered on the habitat and different from the first species.
  5. Answer the quiz.

Travail d’application A1

  1. Importez a01_choice_filter.xlsx et testez : combien d’espèces sont proposées pour chaque habitat ?
  2. Dans la seconde partie, cochez Poulpe, Seiche et Huître : combien de choix la dernière question affiche-t-elle ?
  3. Ajoutez un choix autre (Autre espèce) affiché pour tous les habitats, et une question text Précisez affichée seulement quand autre est choisi.
  4. Ajoutez une question espece_secondaire (Deuxième espèce observée), même liste, filtrée sur l’habitat et différente de la première espèce.
  5. Répondez au quiz.
