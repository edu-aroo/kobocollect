5 · Look at and download the data5 · Consulter et télécharger les données

~2 h

By the end of this session you will be able to

  • look at the data in the DONNÉES (DATA) tab: table, filters, reports, map, photo gallery;
  • correct a submission and give it a validation status;
  • choose the right export (XLS or CSV, labels or XML values, options) and download it;
  • recognise every column of an export, including the metadata (_id, _uuid, _submission_time, _index…);
  • answer simple questions on the export with Excel (COUNTIF, AVERAGEIF, pivot table).

À la fin de cette séance vous saurez

  • consulter les données dans l’onglet DONNÉES (DATA) : tableau, filtres, rapports, carte, galerie de photos ;
  • corriger une soumission et lui donner un statut de validation ;
  • choisir le bon export (XLS ou CSV, étiquettes ou valeurs XML, options) et le télécharger ;
  • reconnaître chaque colonne d’un export, y compris les métadonnées (_id, _uuid, _submission_time, _index…) ;
  • répondre à des questions simples sur l’export avec Excel (NB.SI, MOYENNE.SI, tableau croisé dynamique).

The data of the first quarterLes données du premier trimestre

Simulated context. The landing survey ran from 5 January to 27 March 2026 in the five villages, with three enumerators (accounts enq_fara, enq_tojo, enq_mamy) using KoboCollect. On 15 February the form was redeployed: the choice Crabe was added to the species list (version 2026-02-v2). The supervisor approved part of the forms. You download the data to prepare the quarterly summary for the cooperative.

Download the two exports of the same data: ⇩ k05_debarquements_xml.xlsx (XML values and headers) and ⇩ k05_debarquements_labels.xlsx (labels).

Type of data: one row per landing (120 submissions); counts, weights, choices, GPS points, photos, and metadata.

Contexte simulé. L’enquête débarquements a eu lieu du 5 janvier au 27 mars 2026 dans les cinq villages, avec trois enquêteurs (comptes enq_fara, enq_tojo, enq_mamy) utilisant KoboCollect. Le 15 février, le formulaire a été redéployé : le choix Crabe a été ajouté à la liste des espèces (version 2026-02-v2). Le superviseur a validé une partie des fiches. Vous téléchargez les données pour préparer le bilan trimestriel de la coopérative.

Téléchargez les deux exports des mêmes données : ⇩ k05_debarquements_xml.xlsx (valeurs et en-têtes XML) et ⇩ k05_debarquements_labels.xlsx (étiquettes).

Type de données : une ligne par débarquement (120 soumissions) ; comptages, poids, choix, points GPS, photos et métadonnées.

Edit and validateModifier et valider

  • Edit: opens the submission in the web form; correct the answer and submit. The original is replaced (keep a note of the change, e.g. in a “corrections” sheet).
  • Validation status: Approuvé (Approved), Non approuvé (Not Approved), En attente (On Hold). It does not change the data; it adds the column _validation_status to the export, so that you can keep only approved forms in the analysis. A simple rule: the supervisor approves after checking the form with the enumerator.
  • Modifier : ouvre la soumission dans le formulaire web ; corrigez la réponse et envoyez. L’original est remplacé (notez la modification, ex. dans une feuille « corrections »).
  • Statut de validation : Approuvé (Approved), Non approuvé (Not Approved), En attente (On Hold). Il ne change pas les données ; il ajoute la colonne _validation_status à l’export, pour ne garder que les fiches validées dans l’analyse. Règle simple : le superviseur valide après avoir vérifié la fiche avec l’enquêteur.

Create an exportCréer un export

DONNÉES (DATA) → Téléchargements (Downloads):

  1. Sélectionner le type d’export (Select export type): XLS (Excel, one sheet per table — the best choice), CSV (one table, main data only), GeoJSON, SPSS labels, KML (GPS), media attachments (ZIP of photos).
  2. Format des valeurs et des en-têtes (Value and header format):
    • Étiquettes (Labels (default)) — headers = question labels, values = choice labels (Pêche à pied (glanage)): easy to read, for a quick look or for partners;
    • Valeurs et en-têtes XML (XML values and headers) — headers = name, values = choice name (glanage): short, stable, the right choice for analysis (Excel formulas, R);
    • labels in one of the languages of the form.
  3. Options avancées (Advanced options) — the main ones (Level 3 explains them in detail):
    • Exporter les questions à choix multiples en… (Export Select Many questions as…) — for select_multiple: one column with all the choices + one 0/1 column per choice (default), only the separate columns, or only the single column;
    • Inclure les données de toutes les versions (Include data from all versions) — keep the columns of every version deployed (keep it ticked);
    • Inclure les groupes dans les en-têtes (Include groups in headers) — group/question headers (Intermediate level);
    • Stocker les dates et les nombres en texte (Store date and number responses as text), Inclure les URL des médias (Include media URLs), Sélectionner les questions à exporter (Select questions to be exported), date range…
  4. EXPORTER (EXPORT). The export is prepared (a few seconds to minutes) and appears in the list below; click TÉLÉCHARGER (DOWNLOAD).
  5. Enregistrer la sélection sous… (Save selection as…) saves these settings under a name: next time, apply them in one click.

DONNÉES (DATA) → Téléchargements (Downloads) :

  1. Sélectionner le type d’export (Select export type) : XLS (Excel, une feuille par table — le meilleur choix), CSV (une seule table, données principales seulement), GeoJSON, SPSS labels, KML (GPS), pièces jointes (ZIP des photos).
  2. Format des valeurs et des en-têtes (Value and header format) :
    • Étiquettes (Labels (default)) — en-têtes = libellés des questions, valeurs = libellés des choix (Pêche à pied (glanage)) : faciles à lire, pour un coup d’œil ou des partenaires ;
    • Valeurs et en-têtes XML (XML values and headers) — en-têtes = name, valeurs = name des choix (glanage) : courts, stables, le bon choix pour l’analyse (formules Excel, R) ;
    • les libellés dans l’une des langues du formulaire.
  3. Options avancées (Advanced options) — les principales (le niveau 3 les détaille) :
    • Exporter les questions à choix multiples en… (Export Select Many questions as…) — pour les select_multiple : une colonne avec tous les choix + une colonne 0/1 par choix (défaut), seulement les colonnes séparées, ou seulement la colonne unique ;
    • Inclure les données de toutes les versions (Include data from all versions) — garder les colonnes de toutes les versions déployées (laissez coché) ;
    • Inclure les groupes dans les en-têtes (Include groups in headers) — en-têtes groupe/question (niveau Intermédiaire) ;
    • Stocker les dates et les nombres en texte (Store date and number responses as text), Inclure les URL des médias (Include media URLs), Sélectionner les questions à exporter (Select questions to be exported), plage de dates…
  4. EXPORTER (EXPORT). L’export se prépare (quelques secondes à quelques minutes) et apparaît dans la liste en dessous ; cliquez sur TÉLÉCHARGER (DOWNLOAD).
  5. Enregistrer la sélection sous… (Save selection as…) enregistre ces réglages sous un nom : la prochaine fois, appliquez-les en un clic.

Versions. Submissions of version 2026-01-v1 were filled in when Crabe did not exist: their especes/crabe is 0 because the choice was not offered, not because there was no crab. Always check __version__ before comparing periods.

Quick answers with ExcelRéponses rapides avec Excel

Open the XML export and convert the data into a table (Ctrl + T). Then:

Question Formula (English Excel) Formula (French Excel)
number of landings =COUNTA(A2:A121) or the table’s row count =NBVAL(A2:A121)
landings in Ifaty =COUNTIF(F:F,"ifaty") =NB.SI(F:F;"ifaty")
landings with octopus =SUM(L:L) (column especes/poulpe) =SOMME(L:L)
mean weight with gillnet =AVERAGEIF(J:J,"filet_maillant",R:R) =MOYENNE.SI(J:J;"filet_maillant";R:R)
missing GPS =COUNTBLANK(T2:T121) =NB.VIDE(T2:T121)

For several questions at once, a pivot table (Insert → PivotTable): rows = village, values = count of _id and mean of poids_total.

Ouvrez l’export XML et transformez les données en tableau (Ctrl + L dans Excel en français, Ctrl + T en anglais). Ensuite :

Question Formule (Excel anglais) Formule (Excel français)
nombre de débarquements =COUNTA(A2:A121) ou le nombre de lignes du tableau =NBVAL(A2:A121)
débarquements à Ifaty =COUNTIF(F:F,"ifaty") =NB.SI(F:F;"ifaty")
débarquements avec poulpe =SUM(L:L) (colonne especes/poulpe) =SOMME(L:L)
poids moyen au filet maillant =AVERAGEIF(J:J,"filet_maillant",R:R) =MOYENNE.SI(J:J;"filet_maillant";R:R)
GPS manquants =COUNTBLANK(T2:T121) =NB.VIDE(T2:T121)

Pour plusieurs questions à la fois, un tableau croisé dynamique (Insertion → Tableau croisé dynamique) : lignes = village, valeurs = nombre de _id et moyenne de poids_total.

CSV or XLS? A CSV opened by double-click in a French Excel often shows accents badly or puts everything in one column. Open it with Data → From Text/CSV, choose the UTF-8 encoding and the right separator. The XLS export avoids these problems and keeps the repeat sheets: prefer it.

CSV ou XLS ? Un CSV ouvert par double-clic dans un Excel français affiche souvent mal les accents ou met tout dans une seule colonne. Ouvrez-le avec Données → À partir d’un fichier texte/CSV, choisissez l’encodage UTF-8 et le bon séparateur. L’export XLS évite ces problèmes et garde les feuilles des répétitions : préférez-le.
