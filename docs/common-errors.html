The messages below were produced by pyxform, the converter used by KoboToolbox, with the files of this course. The wording may change a little between versions; the key words stay. Remember: KoboToolbox shows the first error only — correct it and upload again. [row : 9] is the Excel row number (header = row 1).

Les messages ci-dessous ont été produits par pyxform, le convertisseur utilisé par KoboToolbox, avec les fichiers de ce cours.
