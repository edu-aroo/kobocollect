1 · Build a form on the platform (Formbuilder)1 · Construire un formulaire sur la plateforme (Formbuilder)

~2 h

By the end of this session you will be able to

  • create a project from scratch and add questions in the Formbuilder;
  • choose the right question type for each piece of information;
  • set a question as required, add a hint, and give each question a clean data column name;
  • write the choices of a list with a label (what people read) and a value (what is stored);
  • preview the form, save it, and download it as an XLSForm to see what the Formbuilder wrote.

À la fin de cette séance vous saurez

  • créer un projet à partir de zéro et ajouter des questions dans le Formbuilder ;
  • choisir le bon type de question pour chaque information ;
  • rendre une question obligatoire, ajouter une indication (hint) et donner à chaque question un nom de colonne propre ;
  • écrire les choix d’une liste avec un libellé (ce que les gens lisent) et une valeur (ce qui est enregistré) ;
  • prévisualiser le formulaire, l’enregistrer, et le télécharger en XLSForm pour voir ce que le Formbuilder a écrit.

Create a projectCréer un projet

Simulated context. The cooperative wants to test the digital form on one village (Ambolimailaka) for one week before the whole bay. You build a short version of the landing form directly on the platform: date, village, gear, species, weight, number of fishers.

Contexte simulé. La coopérative veut tester le formulaire numérique dans un village (Ambolimailaka) pendant une semaine avant de l’étendre à toute la baie. Vous construisez une version courte de la fiche de débarquement directement sur la plateforme : date, village, engin, espèces, poids, nombre de pêcheurs.

  1. NOUVEAU (NEW) → Construire à partir de zéro (Build from scratch).
  2. Fill in the project details: Project name Débarquements test Ambolimailaka, a one-sentence description, sector (e.g. Environment / Fisheries or the closest one), country Madagascar. → Construire à partir de zéro (Build from scratch) / Create project.
  3. The Formbuilder opens on an empty form. At the top: the form title, Aperçu (Preview), ENREGISTRER (SAVE), and a button to close. In the middle: the questions. On the right (or with the ⚙ icon): the form settings (metadata collected automatically).
  1. NOUVEAU (NEW) → Construire à partir de zéro (Build from scratch).
  2. Remplissez les détails du projet : Nom du projet Débarquements test Ambolimailaka, une description d’une phrase, le secteur (ex. Environnement / Pêche ou le plus proche), le pays Madagascar. → Créer le projet.
  3. Le Formbuilder s’ouvre sur un formulaire vide. En haut : le titre du formulaire, Aperçu (Preview), ENREGISTRER (SAVE), et un bouton pour fermer. Au centre : les questions. À droite (ou avec l’icône ⚙) : les paramètres du formulaire (métadonnées collectées automatiquement).

Add a questionAjouter une question

  1. Click the + button (Ajouter une question (Add question)), type the question label (what the enumerator reads), e.g. Date du débarquement.
  2. Click + Add question: the list of types appears. Choose Date.
  3. The question is created. Click it to edit the label; use the ⚙ icon (Paramètres de la question (Question settings)) to open its settings.
  4. To move a question, drag it by its left edge. To copy or delete it, use the icons on its right.

Repeat for every question. Always write the label first, then choose the type: the Formbuilder uses the label to propose a column name.

  1. Cliquez sur le bouton + (Ajouter une question (Add question)), tapez le libellé de la question (ce que lit l’enquêteur), ex. Date du débarquement.
  2. Cliquez sur + Ajouter une question : la liste des types apparaît. Choisissez Date.
  3. La question est créée. Cliquez dessus pour modifier le libellé ; l’icône ⚙ (Paramètres de la question (Question settings)) ouvre ses paramètres.
  4. Pour déplacer une question, faites-la glisser par son bord gauche. Pour la copier ou la supprimer, utilisez les icônes à sa droite.

Recommencez pour chaque question. Écrivez toujours le libellé d’abord, puis choisissez le type : le Formbuilder se sert du libellé pour proposer un nom de colonne.

Choose the right typeChoisir le bon type

The type decides what the enumerator can enter and how the answer is stored. A good type is your first defence against errors.

Formbuilder type XLSForm name Use it for Example
Texte (Text) text free text: names, remarks name of the captain
Nombre (Number) integer whole numbers (counts) number of fishers: 3
Décimal (Decimal) decimal numbers with decimals (measurements) weight: 12.5 kg
Sélectionner un (Select One) select_one one answer in a list village, gear
Sélectionner plusieurs (Select Many) select_multiple several answers in a list species landed
Date date a date (calendar) landing date
Point geopoint GPS position (latitude, longitude, altitude, accuracy) landing site
Photo image a photo taken with the device photo of the catch
Note note a text shown to the enumerator, no answer instructions
Calcul (Calculate) calculate a value computed by the form (Intermediate level) value = weight × price

Other useful types: Time, Date and time, Audio, Video, Barcode/QR code, Acknowledge (a box to confirm, e.g. consent), Ranking (Intermediate level), Line and Area (GPS traces and polygons).

Le type décide ce que l’enquêteur peut saisir et comment la réponse est enregistrée. Un bon type est votre première protection contre les erreurs.

Type du Formbuilder Nom XLSForm À utiliser pour Exemple
Texte (Text) text texte libre : noms, remarques nom du chef de pirogue
Nombre (Number) integer nombres entiers (comptages) nombre de pêcheurs : 3
Décimal (Decimal) decimal nombres à virgule (mesures) poids : 12,5 kg
Sélectionner un (Select One) select_one une seule réponse dans une liste village, engin
Sélectionner plusieurs (Select Many) select_multiple plusieurs réponses dans une liste espèces débarquées
Date date une date (calendrier) date du débarquement
Point geopoint position GPS (latitude, longitude, altitude, précision) site de débarquement
Photo image une photo prise avec l’appareil photo de la capture
Note note un texte affiché à l’enquêteur, sans réponse consignes
Calcul (Calculate) calculate une valeur calculée par le formulaire (niveau Intermédiaire) valeur = poids × prix

Autres types utiles : Heure, Date et heure, Audio, Vidéo, Code-barres/QR code, Acquittement (une case à cocher pour confirmer, ex. consentement), Classement (niveau Intermédiaire), Ligne et Zone (traces GPS et polygones).

Three classic mistakes.

  • A count typed as text: you get “3”, “trois”, “3 pers.” and you cannot compute anything. Use integer.
  • A village typed as text: you get six spellings. Use select_one with a list.
  • A weight as integer: “12.5” is refused, the enumerator types “12” or “125”. Use decimal.

Trois erreurs classiques.

  • Un comptage saisi en texte : vous obtenez « 3 », « trois », « 3 pers. » et vous ne pouvez rien calculer. Utilisez integer.
  • Un village saisi en texte : vous obtenez six orthographes. Utilisez select_one avec une liste.
  • Un poids en entier : « 12,5 » est refusé, l’enquêteur tape « 12 » ou « 125 ». Utilisez decimal.

Choices: label and valueLes choix : libellé et valeur

For a Select One or Select Many question, type each option under the question. Each option has two parts:

  • the label: what the enumerator reads (Filet maillant), with spaces, accents, capitals;
  • the value (XML value, shown as AUTOMATIC until you change it): what is stored in the data (filet_maillant). Short, lowercase, no spaces, no accents.

The Formbuilder creates the value automatically from the label. Check it: Pêche à pied (glanage) gives a long, awkward value. Click the value and replace it with glanage. Change the values before collecting: changing them later splits your data in two (old and new codes).

Pour une question Sélectionner un ou Sélectionner plusieurs, tapez chaque option sous la question. Chaque option a deux parties :

  • le libellé : ce que lit l’enquêteur (Filet maillant), avec espaces, accents, majuscules ;
  • la valeur (XML value, affichée AUTOMATIC tant que vous ne la changez pas) : ce qui est enregistré dans les données (filet_maillant). Courte, en minuscules, sans espace ni accent.

Le Formbuilder crée la valeur automatiquement à partir du libellé. Vérifiez-la : Pêche à pied (glanage) donne une valeur longue et peu pratique. Cliquez sur la valeur et remplacez-la par glanage. Changez les valeurs avant de collecter : les modifier plus tard coupe vos données en deux (anciens et nouveaux codes).

Question settingsLes paramètres d’une question

Click ⚙ on a question. The first tab (Question options) holds the most important settings:

Setting XLSForm column What it does
Nom de colonne de données (Data Column Name) name the column name in the export. Short, lowercase, no spaces, no accents, unique: poids_total, not Poids_total_débarqué_kg
Indice (Hint) hint a help text shown under the label, in grey: unit, how to measure, examples
Réponse obligatoire (Mandatory response) required Yes: the enumerator cannot go further without answering
Default response default a value already filled in (use with care: people forget to change it)
Appearance appearance how the question looks (e.g. minimal = a drop-down list)

The other tabs, Logique de saut (Skip logic) and Critères de validation (Validation criteria), are seen at the Intermediate level (relevant and constraint).

Cliquez sur ⚙ sur une question. Le premier onglet (Options de la question) contient les réglages les plus importants :

Réglage Colonne XLSForm Ce qu’il fait
Nom de colonne de données (Data Column Name) name le nom de la colonne dans l’export. Court, minuscules, sans espace ni accent, unique : poids_total, pas Poids_total_débarqué_kg
Indice (Hint) hint un texte d’aide affiché sous le libellé, en gris : unité, façon de mesurer, exemples
Réponse obligatoire (Mandatory response) required Oui : l’enquêteur ne peut pas avancer sans répondre
Réponse par défaut default une valeur déjà remplie (à utiliser avec prudence : on oublie de la changer)
Apparence appearance l’aspect de la question (ex. minimal = une liste déroulante)

Les autres onglets, Logique de saut (Skip logic) et Critères de validation (Validation criteria), sont vus au niveau Intermédiaire (relevant et constraint).

Which questions should be required? Those without which the record is useless (date, village, weight), and those you want answered by everybody. Do not make everything required: an enumerator blocked by a question that has no answer (“age” of a captain who does not know it) will type anything to continue. Better an empty cell than a false value.

Quelles questions rendre obligatoires ? Celles sans lesquelles la fiche est inutilisable (date, village, poids), et celles auxquelles tout le monde doit répondre. Ne rendez pas tout obligatoire : un enquêteur bloqué par une question sans réponse possible (« âge » d’un chef de pirogue qui ne le connaît pas) tapera n’importe quoi pour continuer. Mieux vaut une case vide qu’une valeur fausse.

Metadata collected automaticallyLes métadonnées collectées automatiquement

In the form settings (⚙ at the top right of the Formbuilder), tick the metadata to record without asking anything: start (when the form was opened), end (when it was finished), today (date of the day), deviceid (identifier of the phone), username… start and end are very useful to check the quality of the work: a household interview of 2 minutes or of 6 hours deserves a question to the enumerator.

Dans les paramètres du formulaire (⚙ en haut à droite du Formbuilder), cochez les métadonnées à enregistrer sans rien demander : start (ouverture du formulaire), end (fin), today (date du jour), deviceid (identifiant du téléphone), username… start et end sont très utiles pour contrôler la qualité du travail : un entretien ménage de 2 minutes ou de 6 heures mérite une question à l’enquêteur.

Preview, save, and look behind the scenesPrévisualiser, enregistrer, et regarder les coulisses

  1. Aperçu (Preview) opens the form as the enumerator will see it. Fill it in: check the order, the hints, that required questions block you, that numbers refuse letters.
  2. ENREGISTRER (SAVE), then close the Formbuilder.
  3. In the FORMULAIRE (FORM) tab: Plus d’actions (More actions) → Télécharger XLS (Download XLS). Open the file in Excel: this is an XLSForm. Each question is a row of the survey sheet; the options are in the choices sheet. The Formbuilder is only a friendly way to write this file — Session 2 teaches you to write it directly.
  1. Aperçu (Preview) ouvre le formulaire tel que l’enquêteur le verra. Remplissez-le : vérifiez l’ordre, les indications, que les questions obligatoires vous bloquent, que les nombres refusent les lettres.
  2. ENREGISTRER (SAVE), puis fermez le Formbuilder.
  3. Dans l’onglet FORMULAIRE (FORM) : Plus d’actions (More actions) → Télécharger XLS (Download XLS). Ouvrez le fichier dans Excel : c’est un XLSForm. Chaque question est une ligne de la feuille survey ; les options sont dans la feuille choices. Le Formbuilder n’est qu’une façon conviviale d’écrire ce fichier — la séance 2 vous apprend à l’écrire directement.

In a new project Débarquements test Ambolimailaka, build this form in the Formbuilder:

# Label Type Column name Required Hint / choices (value = label)

2 Village Select One village yes ambolimailaka Ambolimailaka · ifaty Ifaty · mangily Mangily

7 Remarques Text remarque no

Then: preview it and fill it in twice; save; download it with Télécharger XLS (Download XLS) and open it in Excel. Answer the quiz with the help of the form and of your downloaded file.

Ensuite : prévisualisez-le et remplissez-le deux fois ; enregistrez ; téléchargez-le avec Télécharger XLS (Download XLS) et ouvrez-le dans Excel. Répondez au quiz à l’aide du formulaire et de votre fichier téléchargé.

In the downloaded file, the type of a choice question is written with the name of its list: select_one followed by a list name that the Formbuilder generated (often a random code such as ab12cd3). That is why, in XLSForm, you will choose list names yourself.

Dans le fichier téléchargé, le type d’une question à choix est écrit avec le nom de sa liste : select_one suivi d’un nom de liste généré par le Formbuilder (souvent un code au hasard comme ab12cd3). C’est pour cela qu’en XLSForm vous choisirez vous-même les noms de listes.

1 integer · 2 decimal · 3 select_multiple · 4 note · 5 poids_total · 6 the value · 7 under the label · 8 choices · 9 6 (all except Remarques; the Formbuilder writes true or yes depending on the version) · 10 a required question with no possible answer produces false data.

1 integer · 2 decimal · 3 select_multiple · 4 note · 5 poids_total · 6 la valeur · 7 sous le libellé · 8 choices · 9 6 (toutes sauf Remarques ; le Formbuilder écrit true ou yes selon la version) · 10 une question obligatoire sans réponse possible produit des données fausses.
