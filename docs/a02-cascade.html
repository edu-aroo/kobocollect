A2 · Cascading questions (region › district › commune)A2 · Les questions en cascade (région › district › commune)

~2 h 30

By the end of this session you will be able to

  • build a cascade of lists (region › district › commune) where each list depends on the previous answer;
  • write the choices sheet of a cascade from an administrative table, by hand or with R;
  • give unique name values when the same place name exists at two levels or in two districts;
  • use the Formbuilder’s cascading select import, and an external list (select_one_from_file) for very long lists.

À la fin de cette séance vous saurez

  • construire une cascade de listes (région › district › commune) où chaque liste dépend de la réponse précédente ;
  • écrire la feuille choices d’une cascade à partir d’un tableau administratif, à la main ou avec R ;
  • donner des name uniques quand un même nom de lieu existe à deux niveaux ou dans deux districts ;
  • utiliser l’import sélection en cascade du Formbuilder, et une liste externe (select_one_from_file) pour les très longues listes.

Location without spelling mistakesUne localisation sans faute d’orthographe

Simulated context. The reef monitoring network (Session A0) works in three regions. In last year’s spreadsheet, the commune of Saint Augustin is written St Augustin, Saint-Augustin, Anantsono and St Aug., and some communes were attached to the wrong district. You want the divers to choose the region, then a district of that region, then a commune of that district. The administrative table: ⇩ a02_regions_districts_communes.csv · the form: ⇩ a02_cascade.xlsx

Contexte simulé. Le réseau de suivi des récifs (séance A0) travaille dans trois régions. Dans le tableur de l’an dernier, la commune de Saint Augustin est écrite St Augustin, Saint-Augustin, Anantsono et St Aug., et certaines communes étaient rattachées au mauvais district. Vous voulez que les plongeurs choisissent la région, puis un district de cette région, puis une commune de ce district. Le tableau administratif : ⇩ a02_regions_districts_communes.csv · le formulaire : ⇩ a02_cascade.xlsx

The administrative list of this course is a partial example (3 regions, 7 districts, 21 communes), made to learn the method. For a real survey, use the official list (national statistics institute, or the common operational datasets of administrative boundaries published by OCHA on HDX) and check the names with the local authorities: communes are sometimes created, merged or renamed.

La liste administrative de ce cours est un exemple partiel (3 régions, 7 districts, 21 communes), fait pour apprendre la méthode. Pour une vraie enquête, utilisez la liste officielle (institut national de la statistique, ou les jeux de données opérationnels communs des limites administratives publiés par OCHA sur HDX) et vérifiez les noms avec les autorités locales : des communes sont parfois créées, fusionnées ou renommées.

  • Three lists: region, district, commune. Each list has a column named after the level above, that contains the name of the parent: the districts have a column region; the communes have region and district.
  • The name values are slugs: lowercase, no accents, _ instead of spaces (atsimo_andrefana, toliara_ii).
  • The commune names are prefixed with their district (toliara_ii_belalanda): the same name can exist twice (the commune Morombe in the district Morombe; two communes with the same name in two districts). Within a list, every name must be unique — otherwise the upload fails (“Choice names must be unique for each choice list”), unless you set allow_choice_duplicates = yes in settings, which makes the analysis ambiguous. Unique names are safer.

The commune list is filtered by district only. Its region column is not needed for the filter, but it is useful in the analysis (and for a “commune” question asked directly after the region, without district: region = ${region}).

La liste des communes n’est filtrée que par district. Sa colonne region n’est pas nécessaire au filtre, mais elle est utile à l’analyse (et pour une question « commune » posée directement après la région, sans district : region = ${region}).

In Excel. Copy the unique regions (Data → Remove duplicates) into the choices sheet with list_name = region; then the unique region–district pairs with list_name = district; then all the rows with list_name = commune. Build the names with formulas, e.g. =LOWER(SUBSTITUTE(B2," ","_")) (and remove accents with Find and replace).

In R — reproducible, and re-run in one second when the list changes:

Dans Excel. Copiez les régions uniques (Données → Supprimer les doublons) dans la feuille choices avec list_name = region ; puis les paires région–district uniques avec list_name = district ; puis toutes les lignes avec list_name = commune. Construisez les names avec des formules, ex. =MINUSCULE(SUBSTITUE(B2;" ";"_")) (et retirez les accents avec Rechercher et remplacer).

Dans R — reproductible, et relancé en une seconde quand la liste change :

library(dplyr)
adm <- read.csv("a02_regions_districts_communes.csv", encoding = "UTF-8")

slug <- function(x) {                         # "Saint Augustin" -> "saint_augustin"
  x <- iconv(x, "UTF-8", "ASCII//TRANSLIT")    # removes accents
  x <- tolower(gsub("[^A-Za-z0-9]+", "_", x))
  gsub("^_|_$", "", x)
}

regions   <- adm |> distinct(region) |>
  transmute(list_name = "region", name = slug(region), label = region)
districts <- adm |> distinct(region, district) |>
  transmute(list_name = "district", name = slug(district), label = district,
            region = slug(region))
communes  <- adm |>
  transmute(list_name = "commune", name = slug(paste(district, commune)), label = commune,
            region = slug(region), district = slug(district))

choices <- bind_rows(regions, districts, communes)       # missing columns become NA
choices[is.na(choices)] <- ""
stopifnot(!any(duplicated(choices[c("list_name", "name")])))   # unique names per list
writexl::write_xlsx(list(choices = choices), "choices_cascade.xlsx")  # paste into the XLSForm

In the FormbuilderDans le Formbuilder

The Formbuilder can create a cascade of select_one questions from a pasted table: Insérer une sélection en cascade (Insert cascading select). Prepare in Excel a table with the columns list_name, name, label and one column per parent level (the same structure as above), paste it, and click Done: the Formbuilder creates the questions and the filters. It works only for select_one; for anything else (a cascade starting from a select_multiple, filters on several columns), use XLSForm.

Le Formbuilder peut créer une cascade de questions select_one à partir d’un tableau collé : Insérer une sélection en cascade (Insert cascading select). Préparez dans Excel un tableau avec les colonnes list_name, name, label et une colonne par niveau parent (la même structure que ci-dessus), collez-le et cliquez sur Terminé : le Formbuilder crée les questions et les filtres. Cela ne fonctionne que pour des select_one ; pour tout le reste (cascade partant d’un select_multiple, filtres sur plusieurs colonnes), utilisez XLSForm.

Very long lists: external fileTrès longues listes : fichier externe

With thousands of choices (all the fokontany of Madagascar, a list of species), the form becomes slow. Put the list in a CSV file instead of the choices sheet:

  1. CSV with the columns list_name, name, label (+ filter columns), UTF-8;
  2. in survey: select_one_from_file fokontany.csv (instead of select_one fokontany), with the same choice_filter as before;
  3. in KoboToolbox: upload the CSV as a media file of the project (PARAMÈTRES (SETTINGS) → Media), then redeploy.

Keep the choices sheet for short lists: it is easier to check and to translate.

Avec des milliers de choix (tous les fokontany de Madagascar, une liste d’espèces), le formulaire devient lent. Mettez la liste dans un fichier CSV au lieu de la feuille choices :

  1. CSV avec les colonnes list_name, name, label (+ colonnes de filtre), en UTF-8 ;
  2. dans survey : select_one_from_file fokontany.csv (au lieu de select_one fokontany), avec le même choice_filter qu’avant ;
  3. dans KoboToolbox : importez le CSV comme fichier média du projet (PARAMÈTRES (SETTINGS) → Média), puis redéployez.

Gardez la feuille choices pour les listes courtes : elle est plus facile à vérifier et à traduire.

  4. Answer the quiz.
