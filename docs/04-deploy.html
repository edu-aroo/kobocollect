4 · Import, deploy and collect (web and KoboCollect)4 · Importer, déployer et collecter (web et KoboCollect)

~2 h 30

By the end of this session you will be able to

  • import an XLSForm into KoboToolbox, and replace the form of an existing project;
  • read an error message, find the row it points to and correct the file;
  • deploy a form, and redeploy a corrected version without losing data;
  • collect with the web form (Enketo), online or offline, and with KoboCollect on Android;
  • test a form properly, and share the project with your enumerators.

À la fin de cette séance vous saurez

  • importer un XLSForm dans KoboToolbox, et remplacer le formulaire d’un projet existant ;
  • lire un message d’erreur, trouver la ligne qu’il désigne et corriger le fichier ;
  • déployer un formulaire, et redéployer une version corrigée sans perdre de données ;
  • collecter avec le formulaire web (Enketo), en ligne ou hors ligne, et avec KoboCollect sur Android ;
  • tester correctement un formulaire, et partager le projet avec vos enquêteurs.

Import an XLSFormImporter un XLSForm

Simulated context. A volunteer of the cooperative wrote the landing form in Excel from memory. KoboToolbox refuses it. You have to find and correct all the errors before the start of the survey on Monday: ⇩ k04_erreurs.xlsx

Contexte simulé. Un bénévole de la coopérative a écrit la fiche de débarquement dans Excel de mémoire. KoboToolbox la refuse. Vous devez trouver et corriger toutes les erreurs avant le début de l’enquête lundi : ⇩ k04_erreurs.xlsx

New project from a file: NOUVEAU (NEW) → Téléverser un XLSForm (Upload an XLSForm) → drag the .xlsx file or click to choose it → fill in the project details → Create project. KoboToolbox converts the file; if it succeeds, the project opens in the FORMULAIRE (FORM) tab, as a Draft.

Replace the form of an existing project (e.g. a corrected version): open the project → FORMULAIRE (FORM) → Plus d’actions (More actions) → Remplacer le formulaire (Replace form) → choose the file. The project, its sharing settings and its data are kept.

Nouveau projet à partir d’un fichier : NOUVEAU (NEW) → Téléverser un XLSForm (Upload an XLSForm) → glissez le fichier .xlsx ou cliquez pour le choisir → remplissez les détails du projet → Créer le projet. KoboToolbox convertit le fichier ; si cela réussit, le projet s’ouvre dans l’onglet FORMULAIRE (FORM), en Brouillon.

Remplacer le formulaire d’un projet existant (ex. une version corrigée) : ouvrez le projet → FORMULAIRE (FORM) → Plus d’actions (More actions) → Remplacer le formulaire (Replace form) → choisissez le fichier. Le projet, ses partages et ses données sont conservés.

Read an error messageLire un message d’erreur

When the file has a problem, KoboToolbox shows a message and does not create (or replace) the form. Two things to know:

  1. The message gives the sheet and the row number ([row : 9]) — it is the Excel row number, header = row 1.
  2. KoboToolbox stops at the first error. After you correct it, the next upload shows the next error. With six errors, expect up to seven uploads. That is why it pays to check the file yourself before uploading (checklist below).

Quand le fichier a un problème, KoboToolbox affiche un message et ne crée (ou ne remplace) pas le formulaire. Deux choses à savoir :

  1. Le message donne la feuille et le numéro de ligne ([row : 9]) — c’est le numéro de ligne Excel, en-tête = ligne 1.
  2. KoboToolbox s’arrête à la première erreur. Une fois corrigée, l’import suivant montre l’erreur suivante. Avec six erreurs, comptez jusqu’à sept imports. C’est pourquoi il vaut la peine de vérifier le fichier vous-même avant l’import (liste de contrôle plus bas).

Checklist before uploading (it catches most errors in two minutes):

  1. Sheet names: survey, choices, settings, in lowercase.
  2. name column of survey: sort a copy A→Z to see duplicates; look for spaces, accents, names starting with a digit.
  3. Every list after select_one / select_multiple exists in choices with exactly the same spelling.
  4. In choices: no duplicate name inside a list; no spaces in names.
  5. Types spelled correctly (select_multiple, not select_many or select multiple).
  6. No empty row in the middle; nothing written below the last row “by mistake”.

Liste de contrôle avant l’import (elle attrape la plupart des erreurs en deux minutes) :

  1. Noms des feuilles : survey, choices, settings, en minuscules.
  2. Colonne name de survey : triez une copie A→Z pour voir les doublons ; cherchez les espaces, les accents, les noms qui commencent par un chiffre.
  3. Chaque liste après select_one / select_multiple existe dans choices avec exactement la même orthographe.
  4. Dans choices : pas de name en double dans une liste ; pas d’espace dans les noms.
  5. Types bien orthographiés (select_multiple, pas select_many ni select multiple).
  6. Pas de ligne vide au milieu ; rien d’écrit « par erreur » sous la dernière ligne.

Warnings (in yellow) do not block the import: e.g. a missing translation, or “Use the max-pixels parameter to speed up submission sending” for a photo question. Read them anyway: the photo warning is a good advice — add max-pixels=1024 in the parameters column of the image question to keep photos light (Session 2).

Les avertissements (en jaune) ne bloquent pas l’import : ex. une traduction manquante, ou « Use the max-pixels parameter to speed up submission sending » pour une question photo. Lisez-les quand même : l’avertissement photo est un bon conseil — ajoutez max-pixels=1024 dans la colonne parameters de la question image pour garder des photos légères (séance 2).

Deploy, then redeployDéployer, puis redéployer

  1. In the FORMULAIRE (FORM) tab, check the form with Aperçu (Preview).
  2. Click DÉPLOYER (DEPLOY). The status becomes Deployed: the form can receive data.
  3. After a correction (Remplacer le formulaire (Replace form) or the Formbuilder), the button becomes REDÉPLOYER (REDEPLOY). Click it: the new version replaces the old one for the next forms. The data already received are kept and each submission remembers its version (__version__).

What you can change safely after collection has started: labels, hints, translations, the order of questions, adding questions or choices. What causes trouble: renaming a name (the export then has an old and a new column), changing a choice name (old and new codes mixed), changing the type of a question (e.g. text → integer). KoboCollect users must download the new version of the form (see below).

  1. Dans l’onglet FORMULAIRE (FORM), vérifiez le formulaire avec Aperçu (Preview).
  2. Cliquez sur DÉPLOYER (DEPLOY). Le statut devient Déployé : le formulaire peut recevoir des données.
  3. Après une correction (Remplacer le formulaire (Replace form) ou le Formbuilder), le bouton devient REDÉPLOYER (REDEPLOY). Cliquez dessus : la nouvelle version remplace l’ancienne pour les prochaines fiches. Les données déjà reçues sont conservées et chaque soumission garde sa version (__version__).

Ce que vous pouvez changer sans risque après le début de la collecte : libellés, indications, traductions, ordre des questions, ajout de questions ou de choix. Ce qui pose problème : renommer un name (l’export a alors une ancienne et une nouvelle colonne), changer le name d’un choix (anciens et nouveaux codes mélangés), changer le type d’une question (ex. texte → entier). Les utilisateurs de KoboCollect doivent télécharger la nouvelle version du formulaire (voir plus bas).

Collect with the web form (Enketo)Collecter avec le formulaire web (Enketo)

Once deployed, FORMULAIRE (FORM) → Collecter les données (Collect data) offers several links. Choose one, then COPIER (COPY) or OUVRIR (OPEN):

Link Use it when
En ligne-Hors ligne (soumissions multiples) (Online-Offline (multiple submission)) enumerators on a phone or tablet (Android or iPhone) with an unstable connection: the form is kept in the browser and the data are sent when the connection comes back
En ligne uniquement (soumissions multiples) (Online-Only (multiple submissions)) data entry on a computer with a good connection (e.g. typing paper forms at the office)
En ligne uniquement (soumission unique) (Online-Only (single submission)) a link sent to respondents who fill in once (online questionnaire)
Application Android (Android application) the instructions and the server address for KoboCollect

By default the link asks for a KoboToolbox login of an account that has access to the project. For an online questionnaire open to anybody, the owner can allow submissions without login in the project settings — only for surveys where that is acceptable.

Une fois déployé, FORMULAIRE (FORM) → Collecter les données (Collect data) propose plusieurs liens. Choisissez-en un, puis COPIER (COPY) ou OUVRIR (OPEN) :

Lien À utiliser quand
En ligne-Hors ligne (soumissions multiples) (Online-Offline (multiple submission)) des enquêteurs sur téléphone ou tablette (Android ou iPhone) avec une connexion instable : le formulaire est gardé dans le navigateur et les données partent quand la connexion revient
En ligne uniquement (soumissions multiples) (Online-Only (multiple submissions)) la saisie sur ordinateur avec une bonne connexion (ex. saisie de fiches papier au bureau)
En ligne uniquement (soumission unique) (Online-Only (single submission)) un lien envoyé à des répondants qui remplissent une fois (questionnaire en ligne)
Application Android (Android application) les instructions et l’adresse du serveur pour KoboCollect

Par défaut, le lien demande la connexion d’un compte KoboToolbox qui a accès au projet. Pour un questionnaire en ligne ouvert à tous, le propriétaire peut autoriser les soumissions sans connexion dans les paramètres du projet — seulement pour les enquêtes où c’est acceptable.

Offline web form: open the Online-Offline link once with a connection on the device (the form is then stored in the browser), and do not clear the browser data while forms are waiting to be sent. Each queued form is sent automatically when the connection returns; check the counter of forms in the queue before leaving the field.

Formulaire web hors ligne : ouvrez le lien En ligne-Hors ligne une fois avec une connexion sur l’appareil (le formulaire est alors gardé dans le navigateur), et n’effacez pas les données du navigateur tant que des fiches attendent d’être envoyées. Chaque fiche en attente part automatiquement quand la connexion revient ; vérifiez le compteur des fiches en attente avant de quitter le terrain.

Collect with KoboCollect (Android)Collecter avec KoboCollect (Android)

Install and configure (once per device)

  1. Install KoboCollect from the Google Play Store (publisher: KoboToolbox).
  2. At the first opening: Saisir manuellement les détails du projet (Manually enter project details). Enter the KoboCollect URL https://kc.kobotoolbox.org (Global server; https://kc-eu.kobotoolbox.org for the EU server), then the username and password of the enumerator → Ajouter (Add).
  3. To configure many phones quickly: configure one, then in its project settings display the QR code of the configuration; on the other phones choose Configurer avec un code QR (Configure with QR Code) and scan it. ⚠ The QR code contains the password: do not post it in a WhatsApp group.

Every day

  1. Télécharger un formulaire (Download form) → tick the form → Get selected. Do it again after each redeploy.
  2. Commencer un nouveau formulaire (Start new form) → choose the form → swipe from right to left to go to the next question. A required question left empty blocks you with a message.
  3. At the end: Finaliser (Finalize) (the form is complete and goes to Ready to send) — or save it as a draft to finish it later (Brouillons (Drafts)).
  4. Prêt à envoyer (Ready to send) → select → Envoyer (Send) when there is a connection. You can also turn on automatic sending in the settings.

The forms stay on the phone after sending (you can see them in Sent). Ask enumerators never to uninstall the app or clear its data before checking that everything has been sent.

Installer et configurer (une fois par appareil)

  1. Installez KoboCollect depuis le Google Play Store (éditeur : KoboToolbox).
  2. À la première ouverture : Saisir manuellement les détails du projet (Manually enter project details). Saisissez l’URL KoboCollect https://kc.kobotoolbox.org (serveur Global ; https://kc-eu.kobotoolbox.org pour le serveur UE), puis le nom d’utilisateur et le mot de passe de l’enquêteur → Ajouter (Add).
  3. Pour configurer rapidement plusieurs téléphones : configurez-en un, puis affichez le QR code de sa configuration dans les paramètres du projet ; sur les autres téléphones, choisissez Configurer avec un code QR (Configure with QR Code) et scannez-le. ⚠ Le QR code contient le mot de passe : ne le publiez pas dans un groupe WhatsApp.

Chaque jour

  1. Télécharger un formulaire (Download form) → cochez le formulaire → Récupérer la sélection. Recommencez après chaque redéploiement.
  2. Commencer un nouveau formulaire (Start new form) → choisissez le formulaire → glissez de droite à gauche pour passer à la question suivante. Une question obligatoire laissée vide vous bloque avec un message.
  3. À la fin : Finaliser (Finalize) (la fiche est complète et passe dans Prêt à envoyer) — ou enregistrez-la comme brouillon pour la finir plus tard (Brouillons (Drafts)).
  4. Prêt à envoyer (Ready to send) → sélectionnez → Envoyer (Send) quand il y a du réseau. Vous pouvez aussi activer l’envoi automatique dans les paramètres.

Les fiches restent sur le téléphone après l’envoi (visibles dans Envoyés). Demandez aux enquêteurs de ne jamais désinstaller l’application ni effacer ses données avant d’avoir vérifié que tout est envoyé.

Share the project with the teamPartager le projet avec l’équipe

PARAMÈTRES (SETTINGS) → Sharing → add the username of each enumerator and give the permissions they need. For an enumerator: View form and Add submissions are enough. For a supervisor: also View submissions and Validate submissions. Only you keep Edit form and Delete. An enumerator’s KoboCollect then shows only the forms shared with them.

PARAMÈTRES (SETTINGS) → Partage → ajoutez le nom d’utilisateur de chaque enquêteur et donnez-lui les autorisations nécessaires. Pour un enquêteur : Voir le formulaire et Ajouter des soumissions suffisent. Pour un superviseur : aussi Voir les soumissions et Valider les soumissions. Gardez pour vous seul Modifier le formulaire et Supprimer. Le KoboCollect d’un enquêteur n’affiche alors que les formulaires partagés avec lui.

Test before the fieldTester avant le terrain

  1. Fill in 5 to 10 test forms with realistic and extreme answers (0 fisher, 300 kg, no species, every gear…), on the devices that will be used in the field.
  2. Check them in DONNÉES (DATA) → Tableau (Table), and download an export (Session 5): are the columns what you expected?
  3. Correct, redeploy, re-test.
  4. Delete the test submissions (in the table, select them → delete) before the real collection starts — or test in a copy of the project.
  5. Train the enumerators with the final version, in the language they will use.
  1. Remplissez 5 à 10 fiches de test avec des réponses réalistes et extrêmes (0 pêcheur, 300 kg, aucune espèce, tous les engins…), sur les appareils qui serviront sur le terrain.
  2. Vérifiez-les dans DONNÉES (DATA) → Tableau (Table), et téléchargez un export (séance 5) : les colonnes sont-elles celles attendues ?
  3. Corrigez, redéployez, re-testez.
  4. Supprimez les soumissions de test (dans le tableau, sélectionnez-les → supprimer) avant le début de la vraie collecte — ou testez dans une copie du projet.
  5. Formez les enquêteurs avec la version finale, dans la langue qu’ils utiliseront.
