3 · Multilingual questionnaires3 · Questionnaire multilingue

~1 h 30

By the end of this session you will be able to

  • write a form in several languages with the columns label::Language (code) and hint::Language (code);
  • translate the choices too, and choose the language shown first with default_language;
  • avoid the “default” language created by a column without language;
  • switch language in the web form and in KoboCollect, and choose the language of the labels in an export.

À la fin de cette séance vous saurez

  • écrire un formulaire en plusieurs langues avec les colonnes label::Langue (code) et hint::Langue (code) ;
  • traduire aussi les choix, et choisir la langue affichée en premier avec default_language ;
  • éviter la langue « default » créée par une colonne sans langue ;
  • changer de langue dans le formulaire web et dans KoboCollect, et choisir la langue des libellés dans un export.

Why several languages?Pourquoi plusieurs langues ?

Simulated context. In the villages of the bay, most fishers speak Malagasy (Vezo dialect); the enumerators read French easily but translate the questions orally, each in their own way. The coordinator, who writes the reports, also wants an English version for the funder. You add Malagasy and English to the landing form: everybody reads the same question, in their language, and the data stay the same whatever language was used.

Contexte simulé. Dans les villages de la baie, la plupart des pêcheurs parlent malgache (dialecte vezo) ; les enquêteurs lisent facilement le français mais traduisent les questions oralement, chacun à sa façon. Le coordinateur, qui rédige les rapports, veut aussi une version anglaise pour le bailleur. Vous ajoutez le malgache et l’anglais à la fiche de débarquement : tout le monde lit la même question, dans sa langue, et les données restent les mêmes quelle que soit la langue utilisée.

A translated question is a better question: when the enumerator translates on the spot, two enumerators ask two slightly different questions, and the answers are no longer comparable. Translate in advance, test the translation with people from the area, and fix the wording before collection.

Une question traduite est une meilleure question : quand l’enquêteur traduit sur le moment, deux enquêteurs posent deux questions un peu différentes, et les réponses ne sont plus comparables. Traduisez à l’avance, testez la traduction avec des personnes de la zone, et fixez la formulation avant la collecte.

One column per languageUne colonne par langue

Replace the column label by one column per language, written label::Language name (code): the name you want to see in the language menu, then the two-letter ISO 639-1 code in brackets. Do the same for hint (and for required_message, constraint_message if you use them).

Remplacez la colonne label par une colonne par langue, écrite label::Nom de la langue (code) : le nom que vous voulez voir dans le menu des langues, puis le code ISO 639-1 à deux lettres entre parenthèses. Faites de même pour hint (et pour required_message, constraint_message si vous les utilisez).

Only the labels are translated, never the name values. filet_maillant stays filet_maillant whatever the language: the data are identical, only the text shown changes. That is what makes the answers comparable between languages.

The Malagasy labels of this course are a draft to show the method: have them checked by a speaker of the local dialect before any real survey.

Seuls les libellés se traduisent, jamais les valeurs name. filet_maillant reste filet_maillant quelle que soit la langue : les données sont identiques, seul le texte affiché change. C’est ce qui rend les réponses comparables d’une langue à l’autre.

Les libellés malgaches de ce cours sont une ébauche pour montrer la méthode : faites-les vérifier par une personne qui parle le dialecte local avant toute enquête réelle.

The default languageLa langue par défaut

settings

In the settings sheet, default_language gives the language shown when the form opens. Its value must be exactly the text after :: in the headers (Français (fr)), same spelling, same accents, same brackets.

The “default” language trap. If one column has no language (a plain label or hint next to label::Français (fr)), KoboToolbox creates an extra language called “default”. The enumerator then sees a language menu with a strange “default” entry, and some questions appear empty in the other languages. KoboToolbox warns you at upload with a message such as:

Language 'default' is missing the survey hint column.

Fix: give a language to every label, hint and message column, in the survey and choices sheets.

Dans la feuille settings, default_language indique la langue affichée à l’ouverture du formulaire. Sa valeur doit être exactement le texte qui suit :: dans les en-têtes (Français (fr)), même orthographe, mêmes accents, mêmes parenthèses.

Le piège de la langue « default ». Si une colonne n’a pas de langue (un label ou un hint simple à côté de label::Français (fr)), KoboToolbox crée une langue supplémentaire appelée « default ». L’enquêteur voit alors un menu de langues avec une entrée « default » étrange, et certaines questions apparaissent vides dans les autres langues. KoboToolbox vous prévient à l’import avec un message comme :

Language 'default' is missing the survey hint column.

Correction : donnez une langue à chaque colonne label, hint et message, dans les feuilles survey et choices.

A missing translation (an empty cell in label::Malagasy (mg)) is not an error, but KoboToolbox gives a warning, and the question shows no text in Malagasy. Before deploying, sort or filter each language column in Excel to find the empty cells.

Une traduction manquante (une cellule vide dans label::Malagasy (mg)) n’est pas une erreur, mais KoboToolbox donne un avertissement, et la question n’affiche aucun texte en malgache. Avant de déployer, triez ou filtrez chaque colonne de langue dans Excel pour trouver les cellules vides.

Languages in the FormbuilderLes langues dans le Formbuilder

Without Excel: in the FORMULAIRE (FORM) tab, Gérer les traductions (Manage translations) lets you name the default language, add a language, and type each translation in a table. It is practical for a short form; for a long one, Télécharger XLS (Download XLS), translate in Excel (it is much faster), then Remplacer le formulaire (Replace form).

Sans Excel : dans l’onglet FORMULAIRE (FORM), Gérer les traductions (Manage translations) permet de nommer la langue par défaut, d’ajouter une langue, et de saisir chaque traduction dans un tableau. C’est pratique pour un formulaire court ; pour un long, Télécharger XLS (Download XLS), traduisez dans Excel (c’est beaucoup plus rapide), puis Remplacer le formulaire (Replace form).

Using the languagesUtiliser les langues

  • Web form (Enketo): a language drop-down menu appears at the top right of the form.
  • KoboCollect: in the form, menu ⋮ → Change language. The language chosen is kept for the next forms.
  • Exports: in DONNÉES (DATA) → Téléchargements (Downloads), the option Format des valeurs et des en-têtes (Value and header format) lets you choose Valeurs et en-têtes XML (XML values and headers) (names, the same in every language) or the labels in one of the languages of the form — e.g. an export with English labels for the funder.
  • Formulaire web (Enketo) : un menu déroulant des langues apparaît en haut à droite du formulaire.
  • KoboCollect : dans le formulaire, menu ⋮ → Changer de langue. La langue choisie est gardée pour les fiches suivantes.
  • Exports : dans DONNÉES (DATA) → Téléchargements (Downloads), l’option Format des valeurs et des en-têtes (Value and header format) permet de choisir Valeurs et en-têtes XML (XML values and headers) (les noms, identiques dans toutes les langues) ou les libellés dans l’une des langues du formulaire — ex. un export avec les libellés anglais pour le bailleur.
