I0 · Calculations (calculate)I0 · Les calculs (calculate)

~2 h 30

By the end of this session you will be able to

  • refer to the answer of another question with ${name};
  • write a calculate row: arithmetic (+ - * div), rounding, conditions with if(), text with concat();
  • handle empty answers with coalesce(), and dates with today() and format-date();
  • show a calculated value to the enumerator in a note, and find it in the export.

À la fin de cette séance vous saurez

  • faire référence à la réponse d’une autre question avec ${name} ;
  • écrire une ligne calculate : arithmétique (+ - * div), arrondi, conditions avec if(), texte avec concat() ;
  • gérer les réponses vides avec coalesce(), et les dates avec today() et format-date() ;
  • montrer une valeur calculée à l’enquêteur dans une note, et la retrouver dans l’export.

Why let the form calculate?Pourquoi faire calculer le formulaire ?

Simulated context. At each landing, the octopus collector of Ambolimailaka buys the catch of the canoe and pays the crew. The cooperative wants to record, for each sale, the value of the sale, the share of each fisher, a size class of the catch and a code for the form — without asking the enumerator to do any mental arithmetic. You add calculate rows to the form: ⇩ i00_calculs.xlsx

Type of data: economic — weights (kg), prices (Ariary/kg), counts.

Contexte simulé. À chaque débarquement, le collecteur de poulpe d’Ambolimailaka achète la capture de la pirogue et paie l’équipage. La coopérative veut enregistrer, pour chaque vente, la valeur de la vente, la part de chaque pêcheur, une classe de taille de la capture et un code pour la fiche — sans demander à l’enquêteur de calculer de tête. Vous ajoutez des lignes calculate au formulaire : ⇩ i00_calculs.xlsx

Type de données : économiques — poids (kg), prix (Ariary/kg), comptages.

A calculation done by the form is done the same way for every submission, at the moment of the interview, and can be shown to the respondent to check it (“So the collector paid you 111 600 Ar, is that right?”). Calculated values are also stored in the data: no formula to rewrite in Excel afterwards.

Un calcul fait par le formulaire est fait de la même façon pour chaque soumission, au moment de l’entretien, et peut être montré au répondant pour vérification (« Le collecteur vous a donc payé 111 600 Ar, c’est bien ça ? »). Les valeurs calculées sont aussi enregistrées dans les données : plus de formule à réécrire dans Excel ensuite.

  • ${name} is replaced by the answer of the question name. ${poids_poulpe} * ${prix_kg} = weight × price.
  • The calculation is re-evaluated each time an answer it depends on changes.
  • A calculation can use another calculation (part_pecheur uses valeur), as long as there is no loop.

Operators and functionsOpérateurs et fonctions

The language of formulas is XPath (the ODK standard). It looks like Excel, with a few traps:

Operation XLSForm Watch out
addition, subtraction, multiplication + - * put spaces around -: ${a} - ${b} (${a}-${b} can be misread)
division div / is not division in XPath: ${valeur} div ${nb_pecheurs}
remainder mod 7 mod 3 = 1
comparison = != < <= > >= = (not ==)
logic and or not(…) lowercase
text 'grosse' text between single quotes

Le langage des formules est XPath (le standard ODK). Il ressemble à Excel, avec quelques pièges :

Empty answersLes réponses vides

If one question of a formula is empty (not answered, or not shown), the result is often empty or NaN. Example: ${revenu_peche} + ${revenu_autre} is empty when revenu_autre was skipped. Use coalesce(${revenu_autre}, 0) to count an empty answer as 0 — but only when 0 is really the right meaning (“no other income”), not when the answer is unknown.

Si une question d’une formule est vide (sans réponse, ou non affichée), le résultat est souvent vide ou NaN. Exemple : ${revenu_peche} + ${revenu_autre} est vide quand revenu_autre a été sauté. Utilisez coalesce(${revenu_autre}, 0) pour compter une réponse vide comme 0 — mais seulement quand 0 a vraiment le bon sens (« pas d’autre revenu »), pas quand la réponse est inconnue.

DatesLes dates

  • Age from a year of birth: int(format-date(today(), '%Y')) - ${annee_naissance}.
  • Number of days between two dates: int(decimal-date-time(${date_fin}) - decimal-date-time(${date_debut})) (dates are counted in days).
  • A code with the date: format-date(today(), '%Y%m%d') → 20260412.
  • Âge à partir d’une année de naissance : int(format-date(today(), '%Y')) - ${annee_naissance}.
  • Nombre de jours entre deux dates : int(decimal-date-time(${date_fin}) - decimal-date-time(${date_debut})) (les dates sont comptées en jours).
  • Un code avec la date : format-date(today(), '%Y%m%d') → 20260412.

Calculations in the exportLes calculs dans l’export

Each calculate gives a column in the export, with its name as header, like a question. In the Formbuilder, the Calculate question type does the same (formula in the question box). A calculation is computed on the device at the time of the interview: if you correct the formula later and redeploy, the old submissions keep their old values — recompute them in Excel or R if needed.

Chaque calculate donne une colonne dans l’export, avec son name comme en-tête, comme une question. Dans le Formbuilder, le type de question Calcul fait la même chose (formule dans la case de la question). Un calcul est fait sur l’appareil au moment de l’entretien : si vous corrigez la formule plus tard et redéployez, les anciennes soumissions gardent leurs anciennes valeurs — recalculez-les dans Excel ou R si nécessaire.

Test a formula quickly: upload the form, open Aperçu (Preview), enter values and read the note. Add a temporary note that shows every intermediate calculation (${valeur} / ${part_pecheur} / ${classe_capture}) while you build the form; delete it before deploying.

Tester une formule rapidement : importez le formulaire, ouvrez Aperçu (Preview), saisissez des valeurs et lisez la note. Ajoutez une note temporaire qui affiche chaque calcul intermédiaire (${valeur} / ${part_pecheur} / ${classe_capture}) pendant la construction ; supprimez-la avant de déployer.
