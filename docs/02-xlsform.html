2 · Write a questionnaire in Excel (XLSForm)2 · Écrire un questionnaire sous Excel (XLSForm)

~2 h 30

By the end of this session you will be able to

  • describe the three sheets of an XLSForm (survey, choices, settings) and their columns;
  • write questions of every basic type, with required, required_message and hint;
  • write choice lists and link them to questions through the list name;
  • respect the rules for name values, and add automatic metadata (start, end, today, deviceid);
  • read an XLSForm written by someone else and find what each row does.

À la fin de cette séance vous saurez

  • décrire les trois feuilles d’un XLSForm (survey, choices, settings) et leurs colonnes ;
  • écrire des questions de chaque type de base, avec required, required_message et hint ;
  • écrire des listes de choix et les relier aux questions grâce au nom de liste ;
  • respecter les règles des valeurs name, et ajouter les métadonnées automatiques (start, end, today, deviceid) ;
  • lire un XLSForm écrit par quelqu’un d’autre et comprendre ce que fait chaque ligne.

Why write the form in Excel?Pourquoi écrire le formulaire dans Excel ?

Simulated context. The one-week test in Ambolimailaka went well. The cooperative now wants the full landing form for its five villages: 11 questions, three choice lists, GPS and photo. The coordinator will maintain it for years and will copy parts of it into other surveys. You write it as an XLSForm. Download the official version of the cooperative to follow this session: ⇩ k02_debarquement.xlsx

Contexte simulé. La semaine de test à Ambolimailaka s’est bien passée. La coopérative veut maintenant la fiche de débarquement complète pour ses cinq villages : 11 questions, trois listes de choix, GPS et photo. Le coordinateur la maintiendra pendant des années et copiera certaines parties dans d’autres enquêtes. Vous l’écrivez en XLSForm. Téléchargez la version officielle de la coopérative pour suivre cette séance : ⇩ k02_debarquement.xlsx

An XLSForm is an ordinary Excel file (.xlsx) with a fixed structure. KoboToolbox reads it and turns it into the form (in the ODK “XForm” format) used by KoboCollect and Enketo. Advantages: you see the whole questionnaire at once, you can copy, paste, sort and search, share the file by e-mail, keep the versions, and reuse blocks between surveys.

Un XLSForm est un fichier Excel ordinaire (.xlsx) avec une structure fixe. KoboToolbox le lit et le transforme en formulaire (au format ODK « XForm ») utilisé par KoboCollect et Enketo. Avantages : on voit tout le questionnaire d’un coup, on peut copier, coller, trier, chercher, partager le fichier par e-mail, garder les versions, et réutiliser des blocs d’une enquête à l’autre.

The names of the sheets and of the column headers are fixed and in English: survey, choices, settings, type, name, label… Write them in lowercase, as here (KoboToolbox tolerates some variations, but other tools do not). A file whose questions are in a sheet called questions is refused: “You must have a sheet named ‘survey’”. The order of the columns does not matter; their names do.

Les noms des feuilles et des en-têtes de colonnes sont fixes et en anglais : survey, choices, settings, type, name, label… Écrivez-les en minuscules, comme ici (KoboToolbox tolère quelques variantes, mais d’autres outils non). Un fichier dont les questions sont dans une feuille nommée questions est refusé : « You must have a sheet named ‘survey’ ». L’ordre des colonnes n’a pas d’importance ; leurs noms, si.

The survey sheetLa feuille survey

One row = one question (or one note, one piece of metadata). Three columns are essential:

  • type — the question type (integer, decimal, text, date, select_one listname…);
  • name — the column name in the data. Unique, short, no spaces;
  • label — the text shown to the enumerator.

Rules for namesRègles pour les noms

KoboToolbox refuses a name that starts with a digit or contains a space or a sign such as (, ', /. It accepts letters, digits, _, - and .. For data that you will analyse in Excel or R, follow stricter rules:

  • lowercase, words separated by _: nb_pecheurs, poids_total;
  • no accents and no - (in R, poids-total is read as “poids minus total”);
  • short but clear: age rather than a, nb_pecheurs rather than nombre_de_pecheurs_a_bord_de_la_pirogue;
  • unique: two questions cannot have the same name;
  • never rename a question once collection has started: the export would then contain two columns.

KoboToolbox refuse un name qui commence par un chiffre ou qui contient une espace ou un signe comme (, ', /. Il accepte les lettres, chiffres, _, - et .. Pour des données que vous analyserez dans Excel ou R, suivez des règles plus strictes :

  • minuscules, mots séparés par _ : nb_pecheurs, poids_total ;
  • sans accents et sans - (dans R, poids-total se lit « poids moins total ») ;
  • court mais clair : age plutôt que a, nb_pecheurs plutôt que nombre_de_pecheurs_a_bord_de_la_pirogue ;
  • unique : deux questions ne peuvent pas avoir le même nom ;
  • ne jamais renommer une question une fois la collecte commencée : l’export contiendrait alors deux colonnes.

The choices sheetLa feuille choices

One row = one option. Three columns: list_name (the name of the list, the same as after select_one / select_multiple), name (the value stored) and label (the text shown). The options appear in the form in the order of the rows.

Une ligne = une option. Trois colonnes : list_name (le nom de la liste, le même qu’après select_one / select_multiple), name (la valeur enregistrée) et label (le texte affiché). Les options apparaissent dans le formulaire dans l’ordre des lignes.

“Other, specify”. Add an option autre (Autre) to the list, then a text question “Précisez” shown only when autre is chosen (relevant, Intermediate level). XLSForm also has the shortcut select_one engin or_other, but it gives a column that is harder to analyse; the explicit autre + text question is clearer.

« Autre, précisez ». Ajoutez une option autre (Autre) à la liste, puis une question text « Précisez » affichée seulement quand autre est choisi (relevant, niveau Intermédiaire). XLSForm a aussi le raccourci select_one engin or_other, mais il donne une colonne plus difficile à analyser ; l’option autre + une question texte explicite est plus claire.

One header row and one row of values. All columns are optional, but fill in at least:

  • form_title — the title shown at the top of the form and in KoboCollect;
  • form_id — an identifier without spaces (debarquement_ranobe);
  • version — a text that changes at each new version (2026-01-v1, then 2026-02-v2). KoboToolbox also records its own version code for each deployment (column __version__ of the export).

Other useful settings: default_language (Session 3), style (pages = one question per screen in the web form), allow_choice_duplicates.

Une ligne d’en-têtes et une ligne de valeurs. Toutes les colonnes sont facultatives, mais remplissez au moins :

  • form_title — le titre affiché en haut du formulaire et dans KoboCollect ;
  • form_id — un identifiant sans espace (debarquement_ranobe) ;
  • version — un texte qui change à chaque nouvelle version (2026-01-v1, puis 2026-02-v2). KoboToolbox enregistre aussi son propre code de version à chaque déploiement (colonne __version__ de l’export).

Autres réglages utiles : default_language (séance 3), style (pages = une question par écran dans le formulaire web), allow_choice_duplicates.

Good habitsBonnes habitudes

  • Start from a template (the file of this session) rather than an empty file: the headers are already right.
  • Freeze the first row (View → Freeze top row) and widen the columns.
  • Keep one file per version (debarquement_v1.xlsx, debarquement_v2.xlsx) or use the version setting and a change log in an extra sheet (extra sheets are ignored by KoboToolbox).
  • Do not merge cells, do not colour cells to carry information (colours are ignored), do not leave blank rows in the middle of a sheet.
  • Write name values before the labels are final: labels can change, names should not.
  • Partez d’un modèle (le fichier de cette séance) plutôt que d’un fichier vide : les en-têtes sont déjà justes.
  • Figez la première ligne (Affichage → Figer la ligne supérieure) et élargissez les colonnes.
  • Gardez un fichier par version (debarquement_v1.xlsx, debarquement_v2.xlsx) ou utilisez le réglage version et un journal des modifications dans une feuille supplémentaire (les autres feuilles sont ignorées par KoboToolbox).
  • Ne fusionnez pas de cellules, ne colorez pas de cellules pour porter une information (les couleurs sont ignorées), ne laissez pas de lignes vides au milieu d’une feuille.
  • Fixez les valeurs name avant que les libellés soient définitifs : les libellés peuvent changer, les noms ne devraient pas.
