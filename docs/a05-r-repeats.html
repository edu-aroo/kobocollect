A5 · Repeat data spread over several sheets, in RA5 · Les données répétées réparties sur plusieurs feuilles, dans R

~3 h

By the end of this session you will be able to

  • read all the sheets of an export at once into a list;
  • link a repeat sheet to its parent with _parent_index = _index, and a nested repeat to the main sheet in two steps (or directly with _submission__uuid);
  • check the links (counts, orphans) before any analysis;
  • summarise the repetitions at the level above (fish per transect, transects per dive) and build analysis tables, wide or long;
  • write all the clean tables in one Excel file.

À la fin de cette séance vous saurez

  • lire toutes les feuilles d’un export en une fois dans une liste ;
  • relier une feuille de répétition à son parent avec _parent_index = _index, et une répétition imbriquée à la feuille principale en deux étapes (ou directement avec _submission__uuid) ;
  • vérifier les liens (effectifs, orphelins) avant toute analyse ;
  • résumer les répétitions au niveau supérieur (poissons par transect, transects par plongée) et construire des tables d’analyse, larges ou longues ;
  • écrire toutes les tables propres dans un seul fichier Excel.

Three sheets, three levelsTrois feuilles, trois niveaux

Simulated context. Same data as Sessions A3–A4. The network wants, for each protection status: the mean live coral cover per transect, the mean number of fish per transect, the share of large fish (> 20 cm), and the most abundant families. The fish are two levels below the dive: dive › transect › fish observation.

Contexte simulé. Mêmes données qu’aux séances A3–A4. Le réseau veut, pour chaque statut de protection : le recouvrement moyen en corail vivant par transect, le nombre moyen de poissons par transect, la part de grands poissons (> 20 cm), et les familles les plus abondantes. Les poissons sont deux niveaux sous la plongée : plongée › transect › observation de poissons.

Link a repeat to its parentRelier une répétition à son parent

A join brings columns of the parent next to each child row. The key is _parent_index in the child and _index in the parent. Rename _index of the parent first, so that the two _index columns do not get confused:

Une jointure amène des colonnes du parent à côté de chaque ligne enfant. La clé est _parent_index dans l’enfant et _index dans le parent. Renommez d’abord l’_index du parent, pour ne pas confondre les deux colonnes _index :

visites <- kobo$main |>
  mutate(statut_lab = kobo_label(statut, f_form, "statut")) |>
  select(visite_index = `_index`, `_uuid`, site, statut, statut_lab, date_plongee)

transects <- kobo$transects |>
  rename(transect_index = `_index`, visite_index = `_parent_index`) |>
  left_join(visites, by = "visite_index")

transects |> select(site, statut, num_transect, corail_vivant, nb_poissons_transect) |> head(4)
#> # A tibble: 4 × 5
#>   site      statut      num_transect corail_vivant nb_poissons_transect

Nested repeat (fish). Two steps: fish → transect (_parent_index = transect_index), which already carries the dive information:

Répétition imbriquée (poissons). Deux étapes : poissons → transect (_parent_index = transect_index), qui porte déjà l’information de la plongée :

poissons <- kobo$poissons |>
  rename(transect_index = `_parent_index`) |>
  left_join(transects |> select(transect_index, visite_index, num_transect, site, statut, statut_lab),
            by = "transect_index")
nrow(poissons) == nrow(kobo$poissons)       # a left join must not add rows
#> [1] TRUE

Shortcut with the uuid. Every repeat row carries _submission__uuid = the _uuid of its submission: you can attach dive information to the fish in one step, left_join(visites, by = c("_submission__uuid" = "_uuid")). But it does not tell you the transect of each fish: for intermediate levels, use _parent_index.

Raccourci avec l’uuid. Chaque ligne de répétition porte _submission__uuid = l’_uuid de sa soumission : vous pouvez amener l’information de la plongée aux poissons en une étape, left_join(visites, by = c("_submission__uuid" = "_uuid")). Mais cela ne donne pas le transect de chaque poisson : pour les niveaux intermédiaires, utilisez _parent_index.

Functions and arguments used here

Function / argument What it does Value it expects
left_join(x, y, by = "key") keeps every row of x and adds the columns of y whose key matches
  by = c("a" = "b") the key is called a in x and b in y
rename(new = old) renames a column
anti_join(x, y, by) rows of x with no match in y (orphans)

Fonctions et arguments utilisés ici

Fonction / argument Ce qu’il fait Valeur attendue
left_join(x, y, by = "key") garde chaque ligne de x et ajoute les colonnes de y dont la clé correspond
  by = c("a" = "b") la clé s’appelle a dans x et b dans y
rename(new = old) renomme une colonne
anti_join(x, y, by) lignes de x sans correspondance dans y (orphelines)

_index is only valid inside one export file. Never join a repeat sheet from one export with the main sheet of another export (downloaded another day, or with other settings): the numbers do not match. For data downloaded at different dates, use _uuid / _submission__uuid.

_index n’est valable qu’à l’intérieur d’un même fichier d’export. Ne joignez jamais la feuille d’une répétition d’un export avec la feuille principale d’un autre export (téléchargé un autre jour, ou avec d’autres réglages) : les numéros ne correspondent pas. Pour des données téléchargées à des dates différentes, utilisez _uuid / _submission__uuid.

Check the linksVérifier les liens

Three checks to run every time — they find deleted submissions, mixed files and mistakes in the form:

Trois contrôles à lancer à chaque fois — ils détectent les soumissions supprimées, les fichiers mélangés et les erreurs de formulaire :

# 1. orphans: repeat rows whose parent does not exist (should be 0)
anti_join(kobo$transects, kobo$main, by = c("_parent_index" = "_index")) |> nrow()
#> [1] 0
# 2. the number of transects per dive matches the answer nb_transects
n_tr <- count(transects, visite_index, name = "n_saisis")
kobo$main |> select(visite_index = `_index`, nb_transects) |>
  left_join(n_tr, by = "visite_index") |> filter(nb_transects != n_saisis) |> nrow()
#> [1] 0
# 3. the form's calculation matches your own sum
f_tr <- poissons |> group_by(transect_index) |> summarise(total = sum(nombre))
transects |> left_join(f_tr, by = "transect_index") |> filter(total != nb_poissons_transect) |> nrow()
#> [1] 0

Summarise at the level aboveRésumer au niveau supérieur

Most indicators are computed per sampling unit (the transect), then averaged per group. Never average the fish rows directly: a transect with 8 observation rows would weigh 8 times more than a transect with 1.

La plupart des indicateurs se calculent par unité d’échantillonnage (le transect), puis se moyennent par groupe. Ne faites jamais la moyenne directement sur les lignes de poissons : un transect avec 8 lignes d’observation pèserait 8 fois plus qu’un transect avec 1.

# fish per transect, with large fish (> 20 cm), one row per transect
par_transect <- poissons |>
  mutate(grand = classe_taille %in% c("t20_30", "t30p")) |>
  group_by(transect_index, statut_lab) |>
  summarise(poissons = sum(nombre), grands = sum(nombre[grand]), .groups = "drop") |>
  left_join(transects |> select(transect_index, corail_vivant), by = "transect_index")

par_transect |>
  group_by(statut_lab) |>
  summarise(transects = n(), corail = round(mean(corail_vivant), 1),
            poissons_par_transect = round(mean(poissons), 1),
            part_grands = round(100 * sum(grands) / sum(poissons), 1))
#> # A tibble: 4 × 5
#>   statut_lab                       transects corail poissons_par_transect part_grands

#> 1 AMP — réserve (no-take)                  9   42                    79.4        18.3
#> 2 AMP — zone d'utilisation durable        21   34.3                  62.5        16.5
#> 3 LMMA / Dina communautaire               27   29.3                  69.4        10.4
#> 4 Non protégé                             18   20.8                  75.4        11.5

Wide table (one column per family, one row per transect) — the format of many statistical analyses — with pivot_wider(); families never seen on a transect get 0, not NA:

Table large (une colonne par famille, une ligne par transect) — le format de nombreuses analyses statistiques — avec pivot_wider() ; les familles jamais vues sur un transect reçoivent 0, pas NA :

large <- poissons |>
  group_by(transect_index, site, statut, famille) |>
  summarise(n = sum(nombre), .groups = "drop") |>
  pivot_wider(names_from = famille, values_from = n, values_fill = 0)
dim(large)
#> [1] 75 11
