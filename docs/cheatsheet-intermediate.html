RemindersRappels

  • a hidden question is not required and is empty in the data (≠ 0);
  • an empty answer is not checked by constraint (use required);
  • impossible value → constraint; unusual but possible → warning note with relevant;
  • test each constraint with a value just inside and just outside.
  • une question masquée n’est pas obligatoire et est vide dans les données (≠ 0) ;
  • une réponse vide n’est pas contrôlée par constraint (utilisez required) ;
  • valeur impossible → constraint ; inhabituelle mais possible → note d’avertissement avec relevant ;
  • testez chaque contrainte avec une valeur juste dedans et juste dehors.
