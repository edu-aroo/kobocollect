A3 · Downloading data for analysisA3 · Télécharger les données pour l’analyse

~2 h

By the end of this session you will be able to

  • choose every export setting with the analysis in mind, and save them;
  • predict the structure of an XLS export (sheets, headers, metadata, links) from the XLSForm;
  • handle several versions of a form in one export;
  • know the other ways to get the data: synchronous export links, media files, and the API (R package robotoolbox).

À la fin de cette séance vous saurez

  • choisir chaque réglage d’export en pensant à l’analyse, et les enregistrer ;
  • prévoir la structure d’un export XLS (feuilles, en-têtes, métadonnées, liens) à partir du XLSForm ;
  • gérer plusieurs versions d’un formulaire dans un même export ;
  • connaître les autres façons d’obtenir les données : liens d’export synchrone, fichiers médias, et l’API (package R robotoolbox).

The reef data are inLes données des récifs sont arrivées

Simulated context. The 24 dives of May–June 2026 have been sent (accounts hery_rf and lova_rf). L’analyste du réseau travaillera dans R ; le coordinateur veut un fichier lisible pour la réunion annuelle. Vous préparez deux exports des mêmes données : ⇩ a03_suivi_recifs_xml.xlsx (pour R) et ⇩ a03_suivi_recifs_labels.xlsx (pour la lecture).

Type de données : trois niveaux liés — 24 plongées, 75 transects, 425 observations de poissons.

Several versions in one exportPlusieurs versions dans un même export

When the form changed during collection, one export contains all the submissions, each with its __version__:

  • a question added in v2 is empty for v1 submissions (it was not asked — do not count these as “no”);
  • a question removed in v2 keeps its column (if Include data from all versions is ticked), empty for v2 submissions;
  • a renamed question gives two columns: merge them in R (coalesce(new, old));
  • a choice added in v2: its 0/1 column is 0 for v1 submissions although the choice did not exist (Session 5).

Before any comparison between periods, tabulate __version__ and read your changelog.

Quand le formulaire a changé pendant la collecte, un même export contient toutes les soumissions, chacune avec sa __version__ :

  • une question ajoutée en v2 est vide pour les soumissions v1 (elle n’était pas posée — ne les comptez pas comme « non ») ;
  • une question supprimée en v2 garde sa colonne (si Inclure les données de toutes les versions est coché), vide pour les soumissions v2 ;
  • une question renommée donne deux colonnes : fusionnez-les dans R (coalesce(nouveau, ancien)) ;
  • un choix ajouté en v2 : sa colonne 0/1 vaut 0 pour les soumissions v1 alors que le choix n’existait pas (séance 5).

Avant toute comparaison entre périodes, faites un tableau de __version__ et relisez votre journal des modifications.

Other ways to get the dataAutres façons d’obtenir les données

  • Media: export type Media attachments (ZIP) downloads all the photos, in folders per submission. Use max-pixels in the form to keep the ZIP small.
  • Synchronous export link: from a saved export setting, KoboToolbox can give a link that always returns the latest data with these settings — useful to connect Excel (Data → From Web) or Power BI. Keep the link private: it gives access to the data.
  • API: everything can be downloaded by a program with your API key (account settings → Security). In R, the package robotoolbox (on CRAN) uses it: kobo_setup(url = "https://kf.kobotoolbox.org", token = "…"), then kobo_asset_list() and kobo_data(asset), which returns the main table and the repeat tables already linked. Practical for a weekly report; never write the token in a shared script (use an environment variable).
  • Médias : le type d’export Pièces jointes (ZIP) télécharge toutes les photos, dans un dossier par soumission. Utilisez max-pixels dans le formulaire pour garder un ZIP léger.
  • Lien d’export synchrone : à partir d’un réglage d’export enregistré, KoboToolbox peut donner un lien qui renvoie toujours les dernières données avec ces réglages — utile pour connecter Excel (Données → À partir du Web) ou Power BI. Gardez ce lien privé : il donne accès aux données.
  • API : tout peut être téléchargé par un programme avec votre clé API (paramètres du compte → Sécurité). Dans R, le package robotoolbox (sur le CRAN) l’utilise : kobo_setup(url = "https://kf.kobotoolbox.org", token = "…"), puis kobo_asset_list() et kobo_data(asset), qui renvoie la table principale et les tables des répétitions déjà reliées. Pratique pour un rapport hebdomadaire ; n’écrivez jamais le jeton dans un script partagé (utilisez une variable d’environnement).

In this course we work with downloaded XLS files: they work offline, they are a frozen copy of the data at a given date (good for reproducibility: name them with the date, suivi_recifs_2026-06-15.xlsx), and the same code reads them whatever the server.

Dans ce cours, nous travaillons avec des fichiers XLS téléchargés : ils fonctionnent hors ligne, ce sont des copies figées des données à une date donnée (bien pour la reproductibilité : nommez-les avec la date, suivi_recifs_2026-06-15.xlsx), et le même code les lit quel que soit le serveur.

  2. With the course exports, answer the quiz without opening R (Excel only).
  3. Write, for the reef form (a03_suivi_recifs.xlsx), the list of the sheets and the columns you expect before opening the XML export, then check.

Travail d’application A3

  2. Avec les exports du cours, répondez au quiz sans ouvrir R (Excel seulement).
